# Descargas de Urban Pets

Esta carpeta se conserva únicamente como referencia y **no contiene instaladores**.

Los archivos `.exe` y `.deb` se publican en GitHub Releases bajo la etiqueta:

```text
urbanpets-v1.0.0
```

La página `UrbanPets/index.html` enlaza directamente a esa publicación. Esto evita almacenar archivos grandes o punteros de Git LFS dentro del sitio de GitHub Pages.
