Antes de instalar

Lo que Urban Pets sí hace y lo que todavía no hace.

La versión 1.0 está pensada para un refugio que trabaja desde una computadora principal. Preferimos decirlo claramente para que sepas si encaja con tu forma de trabajo.

✓

Sí incluye

  • Registro de mascotas, adoptantes y adopciones.
  • Historial de salud y seguimiento.
  • Documentos PDF y plantillas.
  • Cuentas locales con permisos.
  • Respaldos manuales y automáticos opcionales.
×

No incluye

  • Conexión entre computadoras por LAN o Wi-Fi.
  • Trabajo simultáneo desde varios equipos.
  • Sincronización en la nube.
  • Acceso desde navegador o teléfono.
  • Actualización instantánea entre instalaciones.
💡

Puedes instalar Urban Pets en varias computadoras, pero cada una tendrá su propia información independiente. Para mover datos se utiliza un respaldo; no existe sincronización en tiempo real.

Funciones verificadas

Lo esencial del refugio en una sola aplicación.

Estas funciones trabajan con la información guardada en la computadora donde instalaste Urban Pets.

🐶

Mascotas

Expedientes con fotografía, edad, procedencia, estado, salud, alergias y compatibilidad.

🩺

Salud

Consultas, tratamientos, notas médicas, costos y próximas revisiones.

🏡

Adopciones

Adoptantes, acuerdos, visitas, devoluciones, cambios de tutela y seguimiento.

📄

Documentos

Generación de PDF, expedientes, comprobantes, historiales y plantillas editables.

👥

Cuentas locales

Administradores y colaboradores con permisos e historial dentro de la misma instalación. No son cuentas remotas.

💾

Respaldos

Copias manuales y programación automática opcional en una carpeta que tú elijas. No se suben a la nube por sí solas.

Desinstalación

Haz un respaldo antes de borrar.

La información vive en el mismo equipo. Si deseas conservarla, crea un respaldo antes de desinstalar.

ImportanteLa eliminación completa no se puede deshacer. No uses purge si todavía necesitas los datos y no tienes una copia.
01

Desinstalación normal en LinuxEl paquete puede preguntar si deseas borrar los datos. Algunos centros de software no muestran la pregunta; crea un respaldo primero.

sudo apt remove urbanpets
02

Eliminación completa en LinuxQuita Urban Pets y los datos locales gestionados por el paquete.

sudo apt purge urbanpets
Windows

Abre Configuración → Aplicaciones → Aplicaciones instaladas, busca Urban Pets y selecciona Desinstalar. Revisa cualquier opción relacionada con borrar datos y realiza un respaldo antes.

Preguntas frecuentes

Respuestas directas y sin letras pequeñas.

Lo más importante para decidir si Urban Pets 1.0 es adecuado para tu refugio.

¿Se puede usar desde varias computadoras al mismo tiempo?

No. Urban Pets 1.0 trabaja con una base local en la computadora donde se instala. No tiene conexión por LAN, Wi-Fi, nube ni sincronización entre equipos.

¿Puedo instalarlo en más de una computadora?

Sí, pero cada instalación tendrá información separada. Un registro creado en una computadora no aparecerá automáticamente en otra.

¿Para qué sirven las cuentas de usuario?

Sirven para controlar permisos e historial dentro de la misma instalación. No permiten iniciar sesión desde otro equipo ni trabajar de forma remota.

¿Puedo mover la información a otra computadora?

Sí, mediante un respaldo y una restauración. Es un traslado manual; no es sincronización en tiempo real.

¿La aplicación necesita internet?

No para el uso diario. Internet se utiliza para descargar el instalador, consultar la página o conseguir actualizaciones.

¿Los respaldos se suben automáticamente a la nube?

No. Los respaldos se guardan en la carpeta que elijas. Para tener una copia externa, debes copiarla a otra unidad o a un servicio de nube por tu cuenta.

¿Necesito instalar Java o la base de datos por separado?

Los instaladores están preparados para configurar los componentes necesarios. En Linux, APT puede descargar algunas dependencias del sistema.

¿Qué diferencia hay entre remove y purge?

sudo apt remove urbanpets inicia la desinstalación normal y puede preguntar por los datos. sudo apt purge urbanpets realiza la eliminación completa. Haz un respaldo antes.
