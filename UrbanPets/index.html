Funciones principales

Lo fuerte de Urban Pets está en el trabajo diario.

Está diseñado para ayudarte a trabajar mejor, ahorrar tiempo y tener la información importante siempre localizada.

🐾

Registro de mascotas

Guarda nombre, foto, edad, especie, tamaño, procedencia, observaciones y estado de cada mascota.

🩺

Control de salud

Lleva vacunas, tratamientos, consultas, costos y próximas revisiones en una misma ficha.

🏠

Gestión de adopciones

Relaciona mascotas con adoptantes y conserva el proceso de entrega y seguimiento.

📄

Documentos y PDF

Genera expedientes, comprobantes y otros documentos para guardar o imprimir.

👥

Usuarios locales

Permite crear varias cuentas dentro de la misma computadora para el personal del refugio.

🔐

Privacidad local

La información permanece en el equipo donde trabajas, útil cuando no quieres depender de internet.

Puntos fuertes

¿Por qué sí vale la pena instalarlo?

  • Centraliza el trabajo del refugio en una sola aplicación.
  • Ayuda a tener orden, seguimiento y mejor control diario.
  • Funciona de forma local, sin depender de nube para trabajar.
  • Es práctico para refugios pequeños o medianos que quieren empezar ya.
  • Incluye usuarios, documentos y respaldos.
Antes de instalar

Lo que debes saber, explicado sin rodeos.

  • Una sola computadora: esta versión 1.0 trabaja de forma local.
  • Sin red local en tiempo real: no comparte cambios al instante entre varios equipos.
  • Sin nube: no se entra desde celular o navegador para editar datos.
  • Ideal para comenzar: si después quieres red local, sería una evolución futura.

No es una desventaja escondida: simplemente es una versión enfocada en que funcione bien, se vea bien y sea útil desde el primer día.

Desinstalación básica en Linux

Quita la aplicación, pero normalmente conserva datos de usuario si el sistema así lo maneja.

sudo apt remove urbanpets

Desinstalación más completa

Si quieres intentar quitar también la configuración del paquete, usa:

sudo apt purge urbanpets

Consejo importante

Antes de desinstalar, haz un respaldo si deseas conservar el historial del refugio.

Preguntas frecuentes

Respuestas rápidas y fáciles de entender.

¿Urban Pets 1.0 funciona en varias computadoras a la vez?

No. Esta versión está pensada para una sola computadora. Si instalas otra copia en otro equipo, sería independiente.

¿Necesita internet para trabajar todos los días?

No para el uso diario. Urban Pets guarda su información localmente en la computadora donde está instalado.

¿Sí vale la pena si todavía no tiene red local?

Sí, sobre todo si tu prioridad es ordenar mejor el refugio, tener la información concentrada y empezar a trabajar ya con una base sólida.

¿Puedo crear usuarios para mi equipo?

Sí. Permite varias cuentas de usuario dentro de la misma computadora.

¿Qué pasa si más adelante quiero red local?

Sería una mejora futura. Esta versión 1.0 no trae sincronización automática entre computadoras.
