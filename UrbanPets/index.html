Lo que puedes hacer

Menos papeles sueltos y más tiempo para cuidar.

Urban Pets reúne las tareas principales del refugio en una aplicación clara y fácil de consultar.

🐾

Registrar mascotas

Guarda fotografía, nombre, edad, características, procedencia y estado de cada animal.

🩺

Llevar su salud

Anota consultas, vacunas, desparasitaciones, tratamientos, costos y próximas revisiones.

🤝

Organizar adopciones

Relaciona a cada mascota con su adoptante y conserva el seguimiento de la entrega.

📄

Preparar documentos

Genera expedientes, comprobantes y formatos para guardarlos en PDF o imprimirlos.

👥

Crear varios usuarios

El administrador puede crear cuentas para las personas que trabajan en el mismo equipo.

💾

Hacer respaldos

Conserva copias de seguridad para recuperar la información si ocurre algún problema.

Uso local

Una computadora principal, varios usuarios.

Urban Pets está pensado para instalarse o guardarse en una sola computadora del refugio. En esa misma computadora puedes crear diferentes cuentas para el administrador y los colaboradores.

!

No es un sistema en línea. No comparte información automáticamente entre varias computadoras, celulares o sucursales.

Requisitos mínimos

No necesitas una computadora especial.

Estos son los requisitos recomendados para que Urban Pets funcione de manera cómoda.

💻

Sistema

Windows 10 u 11 de 64 bits, o una distribución Linux moderna de 64 bits.

⚙️

Procesador

Procesador de dos núcleos a 2 GHz o superior.

🧠

Memoria

4 GB de RAM como mínimo. 8 GB recomendados para trabajar con mayor comodidad.

💾

Espacio

2 GB libres para comenzar, además del espacio que ocupen fotografías y respaldos.

🖥️

Pantalla

Resolución mínima de 1366 × 768 para visualizar correctamente todas las ventanas.

🖱️

Accesorios

Teclado y mouse. La impresora es opcional si deseas documentos en papel.

✓

Las versiones finales están pensadas para incluir lo necesario para ejecutar Urban Pets, sin pedir al usuario que busque programas adicionales por separado.

Preguntas frecuentes

Lo más importante, explicado de forma sencilla.

¿Se puede usar en varias computadoras al mismo tiempo?

No. Urban Pets está pensado para funcionar en una sola computadora principal. Dentro de esa computadora sí puedes crear varias cuentas de usuario.

¿Puedo crear usuarios para mis colaboradores?

Sí. El administrador puede crear cuentas diferentes para las personas que trabajan con el sistema en la misma computadora.

¿Necesita internet para trabajar?

No para el uso diario. La información se conserva localmente en la computadora donde está Urban Pets.

¿Qué diferencia hay entre instalable y portable?

El instalable de Windows utiliza un solo archivo .exe y crea un acceso directo. Las versiones portables se descomprimen y funcionan desde su propia carpeta.

¿Puedo copiar la versión portable a otra computadora?

Sí, pero debes mover la carpeta completa y evitar trabajar en dos copias distintas con información diferente. Realiza un respaldo antes de moverla.

¿Necesito impresora?

No. Puedes guardar los documentos en PDF y solamente imprimirlos cuando sea necesario.
