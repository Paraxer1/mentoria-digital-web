Desinstalación en Linux

Quita Urban Pets de forma segura.

Antes de eliminar la aplicación, realiza un respaldo si necesitas conservar información. El paquete puede preguntar si también deseas borrar sus datos.

Importantepurge realiza una eliminación completa. Úsalo únicamente cuando ya no necesites la información de Urban Pets.
01

Desinstalar la aplicaciónEl instalador puede preguntarte si deseas eliminar o conservar los datos.

sudo apt remove urbanpets
02

Eliminar completamenteQuita el paquete, su configuración y los datos gestionados por el instalador.

sudo apt purge urbanpets

Abre Configuración → Aplicaciones → Aplicaciones instaladas, busca Urban Pets y selecciona Desinstalar.

Preguntas frecuentes

Respuestas claras antes de instalar.

Lo más importante sobre la descarga, instalación y uso de Urban Pets.

¿Cuál archivo debo descargar?

En Windows descarga el archivo .exe. En Ubuntu, Debian, Linux Mint, Pop!_OS o derivados descarga el archivo .deb. Los instaladores se sirven desde la publicación oficial de Urban Pets en GitHub Releases.

¿Necesito instalar Java o la base de datos por separado?

El instalador está preparado para configurar los componentes requeridos. En Linux, APT puede descargar dependencias compatibles durante la instalación.

¿La aplicación necesita internet?

No para el trabajo diario. Urban Pets utiliza información almacenada localmente en el equipo donde se instala.

¿Qué diferencia hay entre remove y purge en Linux?

sudo apt remove urbanpets inicia la desinstalación normal y el paquete puede preguntarte qué hacer con los datos. sudo apt purge urbanpets realiza la eliminación completa.

¿Cómo protejo mi información antes de desinstalar?

Abre Urban Pets y genera un respaldo antes de eliminar el programa, especialmente si utilizarás la opción purge.
