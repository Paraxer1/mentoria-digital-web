Versión: 1.0.0
Arquitectura: amd64

Comandos verificados para la página:

Instalar:
  cd ~/Descargas
  sudo apt install ./urbanpets_1.0.0_amd64.deb

Desinstalación normal:
  sudo apt remove urbanpets

Eliminación completa:
  sudo apt purge urbanpets

El paquete actual puede preguntar durante la desinstalación si también deben
borrarse sus datos. La operación purge ejecuta la eliminación completa prevista
por los scripts del paquete. Se recomienda crear un respaldo antes de usarla.
