PUBLICAR URBAN PETS EN MENTORIADIGITALMX.COM
===========================================

1. Sube la carpeta completa "UrbanPets" al directorio público de tu dominio.

2. La página quedará disponible en:

   https://mentoriadigitalmx.com/UrbanPets/

3. La carpeta de descargas debe contener únicamente estos dos instaladores:

   UrbanPets/archivos-descarga/UrbanPets-Windows-Instalador.exe
   UrbanPets/archivos-descarga/urbanpets_1.0.0_amd64.deb

4. No cambies esos nombres sin actualizar también los enlaces dentro de:

   UrbanPets/index.html

5. Para probar la página localmente desde la raíz del proyecto:

   python3 -m http.server 8080

   Después abre:

   http://localhost:8080/UrbanPets/

6. Comandos mostrados para Linux:

   Instalar:
   sudo apt install ./urbanpets_1.0.0_amd64.deb

   Desinstalar:
   sudo apt remove urbanpets

   Eliminar completamente:
   sudo apt purge urbanpets

7. La página usa HTML, CSS y JavaScript propios. No necesita librerías externas.
